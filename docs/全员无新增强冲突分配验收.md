# 全员无新增强冲突分配验收

## 目标

在不拆散原确认组队的前提下，为所有已完成有效问卷的学生生成寝室建议。原组队成员之间已有的强冲突允许保留，但必须向辅导员显示具体复核提醒；不同组队单元之间新增的室友关系不得存在强冲突。

## 已实现规则

1. 同班、同性别独立分配。
2. 已确认的二人、三人、四人组均作为不可拆分单元。
3. 原组队内部已有强冲突不拆组，并在辅导员寝室卡片显示冲突原因。
4. 单人或不同组队单元之间只有在没有强冲突时才能合寝。
5. 优先寻找满足强约束的最少寝室数，再在可行组合中优先生活习惯适配度较高的组合。
6. 无法凑满四人的学生仍进入一至三人的未满寝室，不再因为人数不足而漏掉。
7. 已发布的完整固定四人组在重新生成建议时优先保留原寝室号。

## 边界说明

- “最优”首先指强约束下寝室数量最少；生活习惯分数用于可行方案的优先排序，不宣称穷举证明了所有可行方案中的最高总分。
- 自由补充文字、具体游戏名称和特殊住宿需求不参与自动评分，只供辅导员人工查看。
- 点击“生成分寝建议”只生成预览；只有辅导员点击“确认发布”后，学生端才会看到新结果。

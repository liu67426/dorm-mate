# 宿舍协同系统一周试点业务规则

版本：`pilot-v1`

## 1. 试点边界

- 试点只服务工业机器人1—4班。
- 男女生严格分寝；组队必须同班、同性别。
- 每个班优先使用本班寝室，系统默认禁止跨班组队或自动混寝。
- 1—4班女寝分别为11—12、21—22、31—32、41—42；51号为四个班共用的女寝备用房。
- 1—4班男寝分别为101—111、201—211、301—311、401—411。
- 本班常规寝室放不下的女生可进入51号备用女寝；其他无法安置的学生进入“待人工处理”。
- 1—4班填写码依次为01、02、03、04，学生需同时通过班级、姓名和学号核验。
- 如确需同专业邻班混寝，必须由辅导员审批并记录调整原因。
- 一周试点只设置“学生”和“辅导员”两个角色；全校管理员、楼栋资产库和长期调寝流程留到后续版本。

## 2. 组队优先级

1. 四人组满足“同班、四人均完成问卷、四人均确认、无人加入其他组”后，作为固定组优先安置。
2. 三人组、两人组必须保持为一个整体，再由算法补足缺少人数。
3. 单人参与习惯匹配。
4. 未完成问卷的人不能进入固定组，也不能参与自动匹配。
5. 违规组队由辅导员驳回，系统不得静默拆分或跨班合并。

## 3. 匹配规则

- 先检查硬约束，再计算兼容分。
- 系统不评价、处罚或公开标记吸烟学生，只记录真实吸烟习惯与室友接受程度，用于寻找更合适的组合。
- 默认硬冲突：明确完全不能接受烟味的学生，不与填写“可能在寝室内吸烟”的学生自动匹配。
- 默认高权重维度：作息、安静偏好、吸烟习惯相容性。
- 默认中权重维度：卫生习惯、打鼾、寝室学习场景、游戏开麦。
- 算法比较新成员与整组所有人的兼容性，不只比较新成员与组长。
- 兼容分只用于排序和解释，不能替代辅导员人工审核。

## 4. 分配顺序

1. 按班级和性别隔离数据。
2. 安置审核通过的固定四人组。
3. 将三人组、两人组、单人按人数从多到少排列。
4. 在不违反硬约束的候选组合中，寻找兼容分最高且能凑满4人的组合。
5. 无法凑满4人的学生进入待人工处理清单。
6. 输出每个寝室的组成理由、习惯不相容提示、算法版本和随机种子，方便复核。

## 5. 寝室结果与特殊需求

- 辅导员确定并发布寝室后，学生可查看寝室号和同寝室成员。
- 系统不开放在线抢选床位，具体床位由入住后协商或由辅导员线下协调。
- 需要下铺、无障碍等特殊照顾的学生先提交需求，由辅导员核实后线下安排，不在问卷中公开展示。
- 换床需由辅导员更新正式记录，避免系统结果与实际入住不一致。

## 6. 隐私与公平

- 学生只查看自己的问卷、组队状态、最终寝室和必要的室友基本信息。
- 不向学生公开他人的完整生活习惯答案、特殊需求或算法权重。
- 公开业务规则，不公开精确权重，减少为了“刷匹配”而虚假填报。
- 只收住宿安排必需信息，不收身份证号、家庭住址、游戏账号、密码和消费记录。
- 分配、人工调整、组队驳回和结果发布都需要留下操作记录。

## 7. 试点验收指标

- 问卷完成率。
- 两人组、三人组补位成功率。
- 需要人工处理的人数。
- 入住后调寝申请数量与原因。
- 学生满意度只做匿名汇总，不展示个人评价。
